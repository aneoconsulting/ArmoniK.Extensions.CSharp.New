# API Surface

Quick reference for the main client-side interfaces. See [Core Concepts](../concepts/0.core-concepts.md) for a narrative introduction and [Submitting Tasks](../user-guide/2.submitting-tasks.md)/[Querying with LINQ](../user-guide/3.querying-with-linq.md) for usage patterns.

## `ArmoniKClient`

```csharp
ArmoniKClient(Properties properties, ILoggerFactory loggerFactory);

Properties           Properties   { get; }
ILoggerFactory        LoggerFactory{ get; }
ObjectPool<ChannelBase> ChannelPool{ get; }

IBlobService        BlobService       { get; }
ITasksService       TasksService      { get; }
ISessionService      SessionService    { get; }
IEventsService       EventsService     { get; }
IVersionsService     VersionService    { get; }
IPartitionsService   PartitionsService { get; }
IHealthCheckService  HealthCheckService{ get; }

BlobHandle    GetBlobHandle(BlobInfo blobInfo);
TaskHandle    GetTaskHandle(TaskInfos taskInfos);
SessionHandle GetSessionHandle(SessionInfo session);

Task<SessionHandle> CreateSessionAsync(IEnumerable<string> partitionIds,
                                       TaskConfiguration    taskOptions,
                                       bool                 closeOnDispose,
                                       CancellationToken    cancellationToken = default);
```

## Handles

```csharp
// BlobHandle — async-native; no implicit conversion to BlobInfo
ValueTask<BlobInfo>       GetBlobInfoAsync();
Task<BlobState>          GetBlobStateAsync(CancellationToken = default);
Task<byte[]>              DownloadBlobDataAsync(CancellationToken);
IAsyncEnumerable<byte[]>  DownloadBlobDataWithChunksAsync(CancellationToken);
Task                       UploadBlobDataAsync(ReadOnlyMemory<byte>, CancellationToken);

// SessionHandle — implicitly convertible to SessionInfo, IAsyncDisposable/IDisposable
TaskHandle              Submit(TaskDefinition task, CancellationToken = default);
ICollection<TaskHandle> Submit(ICollection<TaskDefinition> tasks, CancellationToken = default);
Task                     SendDllBlobAsync(DynamicLibrary, string zipPath, bool manualDeletion, CancellationToken);
Task                     WaitCallbacksAsync();
Task                     CancelCallbacksAsync();
// + CancelSessionAsync / CloseSessionAsync / PauseSessionAsync / StopSubmissionAsync / ResumeSessionAsync / PurgeSessionAsync / DeleteSessionAsync

// TaskHandle
ValueTask<TaskInfos>  GetTaskInfosAsync();      // awaits submission if still pending
Task<TaskState>        GetTaskDetailsAsync(CancellationToken);
```

## Task and blob building blocks

```csharp
// TaskDefinition — mutable fluent builder
TaskDefinition WithInput(string inputName, InputBlobDefinition blobDeclaration);
TaskDefinition WithOutput(string outputName, OutputBlobDefinition blobDeclaration);
TaskDefinition WithTaskOptions(TaskConfiguration taskOptions);
TaskDefinition WithLibrary(DynamicLibrary workerLibrary); // optional — only for dynamic workers

// BlobDefinition — abstract base; InputBlobDefinition/OutputBlobDefinition are its only two subclasses
static InputBlobDefinition  FromBlobHandle(BlobHandle handle); // throws ArmoniKSdkException if handle isn't resolved yet
static InputBlobDefinition  FromFile(string blobName, string filePath);
static InputBlobDefinition  FromString(string blobName, string content, Encoding? encoding = null);
static InputBlobDefinition  FromReadOnlyMemory(string blobName, ReadOnlyMemory<byte> content);
static InputBlobDefinition  FromByteArray(string blobName, byte[] content);
static OutputBlobDefinition CreateOutput(string name); // the only OutputBlobDefinition factory
// fluent modifiers — covariant: each subclass's With* returns that same subclass
BlobDefinition WithManualDeletion();
BlobDefinition WithCallback(ICallback callBack);
```

See [Error Handling](./3.error-handling.md) for `ArmoniKSdkException` and common gRPC error codes.
