# CI/CD

GitHub Actions workflows live in [`.github/workflows`](https://github.com/aneoconsulting/ArmoniK.Extensions.CSharp.New/tree/main/.github/workflows).

## `build.yml` — Build and Test

Runs on every push to a branch other than `release`:

1. **`versionning`** — derives a semantic version from `git describe` using [`zerv`](https://github.com/taiki-e/install-action).
2. **`buildProject`** — `dotnet restore` then `dotnet build` the whole solution in `Release`, stamped with the computed version.
3. **`runTests`** — builds and runs `Tests/Tests.csproj`.
4. **`publish`** (after tests pass) — `dotnet pack`s the solution and pushes the resulting packages to nuget.org with `--skip-duplicate`. **Every passing push to a non-release branch publishes a NuGet package** for that commit's derived version.
5. **`buildImages`** (after tests pass) — builds and pushes the multi-arch (`linux/arm64`, `linux/amd64`) `ArmoniK.Extensions.CSharp.DynamicWorker/Dockerfile` image to Docker Hub as `dockerhubaneo/armonik-dynamic-dotnet-worker:<version>`.

## `release.yml` — Release

Triggered by pushing a tag matching `[0-9]+.[0-9]+.[0-9]+`:

- Builds and pushes the dynamic worker image tagged both `:<tag>` and `:latest`.
- Builds, packs (using the tag as the version), and pushes the NuGet packages to nuget.org.

## `code-formatting.yml` — Code Formatting

Runs on every pull request. Installs [JetBrains ReSharper Global Tools](https://www.jetbrains.com/resharper/) and runs:

```bash
jb cleanupcode --profile="Full Cleanup With Headers" ArmoniK.Extensions.CSharp.sln
```

The job fails if this produces any diff (a patch artifact is uploaded for inspection). Run the same command locally before opening a PR to avoid formatting failures — see [Code Style](./3.code-style.md).

## `semantic-pull-request.yml` — Lint PR

Enforces that PR titles follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification, posting an explanatory comment if the title doesn't conform.

## Secrets used

- `NUGET_API_KEY` — publishing to nuget.org.
- `DOCKER_HUB_LOGIN` / `DOCKER_HUB_TOKEN` — publishing the dynamic worker image to Docker Hub.
