# Building and Testing

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download)

## Build the solution

```bash
git clone https://github.com/aneoconsulting/ArmoniK.Extensions.CSharp.New.git
cd ArmoniK.Extensions.CSharp.New

dotnet restore
dotnet build ArmoniK.Extensions.CSharp.sln -c Release
```

CI builds with `-warnAsError:"CS1570;CS1571;CS1572;CS1573;CS1587;CS1591"` — missing or malformed XML doc-comments on public members are treated as build errors. Keep public APIs documented.

## Run unit tests

Unit tests live in `Tests/` and use **NUnit** with **Moq**:

```bash
dotnet build Tests/Tests.csproj -c Release
dotnet test Tests/Tests.csproj -c Release --verbosity normal
```

They exercise the client library against a mocked gRPC `CallInvoker` (`Tests/Configuration/MockedArmoniKClient.cs`) — no real ArmoniK cluster is needed. Configuration for the mocked client comes from `Tests/appsettings.tests.json`.

## Run end-to-end tests

`End2EndTests/` contains real integration tests that submit tasks to a **live ArmoniK cluster** — they are not run in CI and must be run manually:

1. Deploy ArmoniK locally (see the [main ArmoniK docs](https://armonik.readthedocs.io/en/latest/)) or point at an existing cluster.
2. Publish and deploy the E2E worker:
   ```bash
   cd End2EndTests/ArmoniK.EndToEndTests.Worker
   ./DeployWorker.sh          # Linux — publishes, discovers the cluster ingress, rewrites the client's Grpc:EndPoint
   # or DeployWorkerInWsl.ps1 on Windows/WSL
   ```
3. Run the client-side tests:
   ```bash
   dotnet test End2EndTests/ArmoniK.EndToEndTests.Client
   ```

The end-to-end suite covers task priority scheduling, error/abort propagation via callbacks, blob-creation response ordering, and task/partition queries at scale (`GaussProblemClient`, `PriorityClient`, `FailingTaskClient`, `CheckBlobCreationResponseOrderClient`, `TaskSdkClient`).
