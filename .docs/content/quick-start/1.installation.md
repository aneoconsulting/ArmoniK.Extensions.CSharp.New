# Installation

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download) (workers, worker interfaces, examples) — the `Client` and `Common` libraries target `netstandard2.0` so they can be consumed from older runtimes too.
- A running ArmoniK cluster to submit tasks to. See the [main ArmoniK documentation](https://armonik.readthedocs.io/en/latest/) for local or cloud deployment instructions.

## NuGet packages

Four packages are published to [nuget.org](https://www.nuget.org/) from this repository:

| Package | Use it from |
|---|---|
| `ArmoniK.Extensions.CSharp.Client` | Any application that submits tasks to ArmoniK (the "client" side). |
| `ArmoniK.Extensions.CSharp.Common` | Pulled in transitively by the other packages — shared domain types (`BlobDefinition`, `TaskDefinition`, `TaskConfiguration`, ...). |
| `ArmoniK.Extensions.CSharp.Worker` | A worker that hosts the gRPC server and dispatches tasks to your `IWorker` implementation — used by both static and dynamic workers. |
| `ArmoniK.Extensions.CSharp.Worker.Interfaces` | The minimal `IWorker` contract. If your worker only needs to be **dynamically loaded** (see [Static vs. Dynamic Workers](../user-guide/1.static-vs-dynamic-workers.md)), this is the only dependency you need. |

Install the one(s) you need with the .NET CLI:

```bash
# Client application
dotnet add package ArmoniK.Extensions.CSharp.Client

# Static worker (hosts the gRPC server itself)
dotnet add package ArmoniK.Extensions.CSharp.Worker

# Dynamically-loaded worker library (no gRPC hosting, no Program.cs needed)
dotnet add package ArmoniK.Extensions.CSharp.Worker.Interfaces
```

Packages are versioned from git tags (see [Releases](../contrib-and-dev/2.ci-cd.md)); pick the latest published version, or pin to the one matching the ArmoniK cluster version you are targeting.
